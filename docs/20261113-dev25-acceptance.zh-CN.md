## 可用入口

管理器新增“新建制作项目”，现有项目面板增加“编辑主题与规格”“编辑故事大纲”“导出主题与大纲”。表单与 `authoring create/show/preview/save/outline` CLI 共用服务，直接读写现有 brief/story；不会另建一份剧本或执行状态。

| 模块 | 当前行为 |
| --- | --- |
| 新建制作项目 | 选择已有制作分支，填写主题、受众、观众理解目标、标题和规格；独占创建新目录，不覆盖空目录、半成品或旧项目 |
| 主题与规格 | 单独编辑 brief 的观看目标、节奏、时长目标、生成画幅/分辨率、声音与美术；topic、audience、viewer_goal 分开保存 |
| 故事大纲 | 编辑一句话故事、目标、阻碍、选择、结果、落点、开场状态和有序因果事件 |
| 事件与状态 | 稳定事件 ID、前因、观众信息、可见证据及 requires/effects；状态表支持文字、有限数字、布尔值、空值，保留已有嵌套值 |
| 修改预览 | 显示字段差异、整计划错误、请求输入/依赖影响和已有任务；不会自动重映射分镜或重做素材 |
| 保存 | 绑定完整计划来源版本、精确编辑值和任务状态；保存前复验，单层备份和原子替换，旧任务、候选、账本与审核决定保留 |
| 大纲阅读稿 | 输出带来源哈希的 production/outline.md，列主题规格、因果顺序、前后状态、证据与镜头覆盖；修改阅读稿不写回项目 |

表单可以保存 Schema 正确但语义尚未完成的草稿。创建和保存成功不等于可执行或内容通过；生成、渲染与交付仍受原计划和实际审核门槛约束。保存不会批准阶段，已有阶段按原输入哈希自然失效。主题元数据与大纲不会自动变为提示词；请求仍由分镜及实际消费的参数决定。修改生成规格可能使请求输入过期，但不会修改或重新提交旧任务。

耗时哈希与媒体检查放在后台、短任务锁之外；进入保存锁后再次核对计划和任务版本。另一窗口修改、预览后编辑或任务状态变化会保留较新数据并拒绝旧保存。表单销毁时取消未执行的轮询回调；已开始的本地后台操作完成后结束。新建过程先写各层、最后写 project.json，失败或中断可能保留部分目录以供检查；不自动清除，不宣称多文件断电事务。
