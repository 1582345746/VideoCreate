**现在适合在本机怎样测试**

1. 从“剧本到分镜”测试开始：给一个 15–30 秒题材，让 Codex 用 videocreate 建立 F 盘新项目，输出大纲、剧本、分镜和 HTML 预演。明确只策划，不生成。这能验证主创作入口、修改体验与进度。

4. 选择已有本地视频/静帧测试 GIF，或检查角色卡片/素材库的版本复用；不需要上游请求。
5. 真实 API 小样作为单独一轮：先确定精确上游/型号/操作、允许请求数、参数和费用范围，再做已授权请求。本次“梳理与测试使用”没有授予新的收费生成，也未发起它。
