# VideoCreate：并发调度与三支历史样片实测

日期：2026-11-05。代码交付目标为用户已确认的 GitHub `1582345746/VideoCreate`，分支 `codex/videocreate-v3`。

## 结论

生图和视频已经可以按配置并发执行、逐任务记账、保留重试候选，再逐项审核。三个题材均已真实生成素材并拼接为约 60 秒、1280×720、24 fps 的预览，全部通过完整技术解码。它们仍是 `draft_preview / review_pending`，没有获得动态、声音及最终剪辑质量通过回执。

本轮改善了生产与故障恢复能力，但样片仍未达到稳定的电影级第一人称叙事。按采样画面的信息组织判断，《草船借箭》的线索最清楚；两个战争题材的主要问题是机位漂移、行动结果缺失、空间衔接不一致。仅增加提示词或增加重试次数，不能保证改善。

## 本轮已实现与修复

| 模块 | 实际行为与边界 |
|---|---|
| 生图并发 | `assets batch` 先本地校验整批条目，再通过独立图片任务池提交；单项失败保留其他项结果 |
| 视频并发 | 独立 job 并行提交、轮询及下载；有 `depends_on` 的 job 按依赖波次执行，前项未完成时后项阻塞 |
| 配置 | 图片池与视频池分别配置 1–50；示例各为 6，上游提交上限示例为 50。旧配置缺省仍为串行，不自动改用户文件 |
| 上游提交门控 | 只限制创建请求；排队等待期间不预扣该任务请求预算；HTTP 工作不持有项目状态锁 |
| Windows 状态锁 | 在获得锁后初始化锁文件，避免多个新任务同时初始化时异常 |
| 逐项审核 | 完成列表按完成时间排列；图片审核绑定输出哈希；视频继续使用分层、区间及实际证据回执 |
| 图片坏响应 | 保存原始响应并标为 `output_invalid`；`assets reprocess` 重新解码原结果，不创建新图 |
| 定点重试 | 图片和视频的新候选需要明确 job、原因及内容重试/重规划；保存历史，受每项目预算与每 job 次数限制 |
| 已知视频恢复 | 下载前持久化完成响应；下载失败后优先使用原响应，避免再次查询及重复创建。保存结果损坏时回查原 task |
| 下载地址 | 支持上游相对结果 URL；解析后的外部地址不携带上游密钥 |
| Muse 多图 | 一张 `opening-frame` 主图作为 `image.url`；附加 identity/prop/scene 作为 `reference_images[].url`。校验总数及附加数，支持配置 1+6 |
| Muse 时长 | 每次最多 10 秒；一分钟成片使用多个任务本地组装 |
| 声音编译 | 对白镜头同时保留环境声及声音方向，不再遗漏这部分文字指令 |
| 第一人称编译 | framing/camera_position 声明第一人称时追加视点连续性提示；这是提示词约束，不能当作上游硬控制能力 |

并发提交不会自动批准内容；选择某个候选也不会签发质量通过。模型、上游和适配协议仍独立配置，图片使用独立图片绑定，视频使用 aivalux/Sub2API 的 `muse-video`。

本轮采用镜头实际使用一张主图加一张参考图，泸定桥其中一镜仅使用主图；没有用满 7 张进行线上验收。1+6 的请求构造及超限阻止通过离线测试，不等于已证实上游满载接收或多图必然改善效果。恢复任务仍会检查原输入；编译器升级引起的提示词变化也可能触发输入变更保护，恢复旧项目时应保留原版本和输入。

## 抽帧观察与镜头缺陷

每条采用源片在约 0.2、2、4、6、8、9.7 秒抽帧，并记录源文件哈希、候选 ID、图片哈希和采样时间。下表只陈述采样点可见的信息；没有完成实际连续视频理解及听审，不能评价完整动作自然度、对白正确性、枪声同步或最终节奏。

### 飞夺泸定桥

历史范围：1935 年长征途中，红军与国民党守军；剧本方向为西岸向东岸。生成图不能独立证明桥体细节和东西岸方向正确。

| 成片区间 | 采样观察 | 问题与修复方向 |
|---|---|---|
| 0–10 秒 | 灰袖、铁链、破木板、急流提供危险环境信息 | 保留近景材质，校验桥头和桥身布局 |
| 10–20 秒 | 手、木板与铁链关系可读 | 铺板的连续接触过程仍需动态检查 |
| 20–30 秒 | 后段采样已接近桥头及守军 | 下一镜返回桥中，前后位置矛盾；应使用实际结束状态安排后续镜头 |
| 30–40 秒 | 光照变亮，桥头样式和距离改变；未明确看到原计划的燃烧木板 | 不应宣称完成“避火”动作；需单独定义可见结果及场景锚点 |
| 40–50 秒 | 初版后段到达桥头掩体；有外部人物构图 | 重试只剩过桥，缺救援和到达；选回初版保留更多情节信息，但保留视角缺陷 |
| 50–60 秒 | 重试开头能看到扶助戴软帽战友，后段转为外部视角并改变位置 | 服装线索改善，但连续 POV 仍失败，桥岸关系未证明 |

### 平型关大捷

历史范围：1937 年，八路军第 115 师与日军。群众、车型、装备、战术及地形均需进一步历史复核，不能作为战役影像资料。

| 成片区间 | 采样观察 | 问题与修复方向 |
|---|---|---|
| 0–10 秒 | 山路车队与前景步枪建立埋伏位置 | 可作为气氛建立，但需与后镜保持同一道路形状 |
| 10–20 秒 | 侧方战友给出手势，衣袖与步枪延续 | 轮廓暴露的战术合理性需复核 |
| 20–30 秒 | 车的位置发生变化 | 未证实“头车停住、车队被困”的关键结果，导致下一镜战斗动机不够清楚 |
| 30–40 秒 | 采用初版，车、对方士兵与掩体仍能辨识，后段为肩后构图 | 重试丢失道路/车队信息；未采用。不能只凭新提示词把视角问题记为已修好 |
| 40–50 秒 | 初版保留箱体和手的任务信息，后段出现外部人物 | 重试变成绿树道路，没有明确搬运结果，选回初版 |
| 50–60 秒 | 前景枪/手与后段远景构图不一致 | 收尾缺少稳定机位及清楚的任务完成证据 |

### 诸葛亮·草船借箭

题材标为《三国演义》文学改编，第一人称为虚构叙事视点；不作为诸葛亮生平的史实复原，也不以演员面容复现作为本片验收依据。

| 成片区间 | 采样观察 | 问题与修复方向 |
|---|---|---|
| 0–10 秒 | 地图、羽扇、白袖、船舱建立筹谋 | 道具和袖口可继续作为一致性参考 |
| 10–20 秒 | 雾、水面、船只建立接近水寨 | 雾量、船体结构及位置仍需跨镜约束 |
| 20–30 秒 | 鼓、鼓槌与水寨形成动作关联 | 声音和击鼓接触未听审/动态验收 |
| 30–40 秒 | 草束、箭、水花支持借箭结果 | 箭的碰撞、数量变化及手部连续性待复核 |
| 40–50 秒 | 带箭草束、白袖、羽扇延续，出现轮式操舵器 | 时代道具风险；雾与日光过渡明显，不能宣称完成历史道具审核 |
| 50–60 秒 | 船岸与箭束给出返回线索 | 相较战争片，采样信息更容易串联；完整叙事和声音仍待实播检查 |

## 从样片反推的下一轮开发优先级

| 优先级 | 能力 | 可检验的完成条件 |
|---|---|---|
| P0 | 场景与视点连续性 | 同一桥头/道路/船体具有可定位锚点；检查采用片段多个时间点及相邻镜头，而非只对首帧 |
| P0 | 行动结果验收 | 给停车、铺板、援手、搬箱等动作各定义可观察结果；结果没出现时不允许把对应剧情当作已发生 |
| P0 | 依赖与帧交接实际使用 | 连续动作使用已选片段的实际末段截图作为后镜输入并保存来源；独立插镜仍可并发，避免把全片强制串行 |
| P0 | 完整动态/听审 | 对采用区间实际播放，检查视角、接触、枪声/对白、剪辑衔接；按实际字节与时间段记录，抽帧不替代 |
| P1 | 参考图角色分离 | 服装/武器使用局部参考，构图单独控制；避免一张大场景母图让每个新镜头都回到起点 |
| P1 | 镜头覆盖与剪辑 | 生成 10 秒不等于必须采用 10 秒；使用实际有效窗口、反应/道具/环境插镜组织节奏，不能仅六段等长拼接 |
| P1 | 历史资产检查 | 对帽型、服装、车辆、武器和船用器具建立按年代的参考与排除项；错误道具应更换或重做局部画面 |
| P1 | 对白与声音独立处理 | 原生音轨先听审，再决定是否用独立配音、环境声与准确字幕修复；当前字幕文件为空，不能称为已完成对白字幕 |
| P2 | 连续集与能力路由 | 先验收一集的结尾状态与角色资产，再继承至下集；按模型实际镜头表现选择已验证能力，不凭目录名称判断质量 |

已有帧交接、候选选择和审片包可支撑上述工作，但本轮没有把全部后续目标实现为自动内容判断。当前更适合先做 10–20 秒、单一动作或稳定视点的历史氛围短片，或有来源与独立旁白的科普片；在视角、动作结果、场景和声音均通过一集验收前，不宜直接扩展到 20 集复杂战争连续剧。
