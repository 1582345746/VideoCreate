## 已实现的使用流程

普通用户在本机 Web 添加上游，只填 HTTPS URL 和 Key 即可保存；名称默认使用域名，名称与备注可选。Web 采用 Vue/TypeScript 静态页面和 FastAPI 薄服务，共享现有 JSON、DPAPI、修订、锁、校验和备份。运行页面不需要 Node，也不把 Web 依赖强加给纯 CLI。

保存后由用户明确点击只读目录检查，或让 Codex 使用已有合同整理精确型号、协议和参数。缺少 `/models` 不会撤销已保存的上游。目录导入只形成禁用草稿。内置一键合同目前仅覆盖 `https://xingapi.top/v1` 的 `seedance2.5-V` 文生视频候选：720p、9:16、整数 5–30 秒、模型默认声音。其余型号和操作继续由 Codex/CLI 按明确文档维护，不能凭名称推定。

页面包含上游管理、模型目录、默认选择、检查与记录、设置五个入口。具备上游新增/复制资料/改名称备注/同账户换钥/归档，图片视频独立默认，模型资料及可选结构化能力/报价/档位与高级 JSON 维护，筛选比较、逐操作证据、匿名诊断、备份恢复和损坏配置修复。视频创作、生成、恢复、剪辑和审片仍由 Codex + 技能 + CLI 完成。

## 本批补充实现

四类 Web 草稿各有白名单与来源规则，显式恢复、丢弃、合并后手动保存。模型保留备注空白、原始排序文本及可验证的高级 JSON；含未知字段、语法损坏或凭据式来源 URL 的高级组不暂存并提示，恢复不完整时高级提交默认关闭。备份选择只保存受控哈希，不保存原配置。服务被强制终止后换实例和会话，只有明确恢复才认领草稿，不自动写配置。

浏览器不再是草稿唯一索引：主动展开“本机未提交草稿”并点击读取后，按配置文件列出有界分页的类型、时间、状态和不透明标识，不列名称、备注、URL 或表单内容。丢失 sessionStorage 仍可明确选中恢复输入；页面不自动列出或恢复。过期、版本不支持及损坏记录保留供明确按版本丢弃。save/claim/discard 均按精确文件哈希检查并共用进程锁；相同 Cookie 的接管也改变版本。冲突暂停自动暂存、保留输入，提供另存新草稿；旧窗口不能覆盖、删除或复活较新/已丢弃的记录。配置成功保存后的草稿清理冲突只作提示，不将成功误报为失败，也不锁死下一次新表单。

结构化常用声明/执行限制、报价来源和价格档位与高级 JSON 共用单一父表单。展示报价与预算价格分开，新增/删除档位不写盘；清空可选价格后保存删除该组，未知不为零。typed 图片/视频/音频结构化限制和条件时长已补齐：数量、字节、MIME/角色、尺寸/时长、音频采样/声道、总数/总字节、有效秒数及七类组合与 JSON 同步。保留其他能力字段；不自动选协议，未填合同保持未知。启用参考操作缺少必需限制时核心拒绝保存。额外精确合同仍待补证；预算支持每请求/每秒，以及图片按明确请求出图张数计价；每请求费可与每秒费或每张费相加。按张不能混用时长语义，省略 n 时张数未知，其他单位保留展示报价。
