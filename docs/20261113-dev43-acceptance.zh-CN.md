## 使用与报告范围

管理器新增“脱敏诊断导出”，CLI 新增 `providers diagnostics` 与 `providers diagnostics-export`。读取磁盘已保存配置，可选择当前或全部上游，先预览实际报告，再导出新的 JSON。管理器未保存输入不计入报告，也不因诊断而应用或保存。

报告汇总配置结构状态、软件版本、FFmpeg/FFprobe 是否可找到、接入启用/草稿/归档、协议、数值及标准参数限制、报价核实状态/档位数、路线和默认关系、缓存目录变化数量，以及按操作区分的目录/合同/小样/质量证据摘要。过期证据单独计数。

默认采用报告内部代号。可选加入准确型号/binding/上游 ID 和 API 主机名，主机不包含 URL 路径、查询或签名。账户与凭据版本、密钥及引用/环境变量名、备注、自由文本、完整 URL、路径、任务号、原始日志/回执和价格金额均不导出。标准分辨率/画幅等标签保留，自定义字符串省略并计数。诊断报告不能作为配置导入。

诊断不查找外部凭据、不解密 DPAPI、不读取环境密钥、不联网、不运行 FFmpeg、不生成媒体。保存 JSON 中已有的明文凭据值只在本机用于清理可选标识，不输出；计数明确为 `external_credential_reads: 0`。证据核对可能读取其引用文件和对应质量任务，不枚举全部项目。报告不能证明当前密钥可用、完整请求就绪、实际支付或艺术质量。

## 导出与证据保护

本机预览封装包含来源 token 和范围选项，供第二步复核；对外分享导出的报告文件。导出重新读取配置字节和当前摘要，配置、目录观察、证据或依赖摘要变化后必须重新预览。文件必须是新的 `.json`，同目录临时文件通过硬链接原子发布，不覆盖已有文件；需要支持硬链接的本机文件系统。

窗口范围/披露选项改变会清除旧预览。重复点击只执行一次；预览中关闭窗口可分离 UI，正在写出时阻止用户关闭。缺失、损坏、结构无效和不支持的新配置只产生有限状态/问题数量，不复制原文；CLI 可在管理器无法启动时诊断。

读取证据沿用录入时的严格校验：未知结果、缺失审阅者/必要任务号、与通过结论矛盾的布尔检查等不能成为通过摘要，原始文件保持。各操作和证据层独立，不从文生视频通过推导多媒体参考通过。
