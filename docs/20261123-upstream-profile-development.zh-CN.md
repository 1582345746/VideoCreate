# 2026-11-23 上游配置完善开发清单

目标：用户逐次提供上游 URL、Key、API 文档、模型参数和价格后，资料长期存于本机；新对话说出上游名称就能读取相应合同并使用正确账户与模型。独立 VideoCreate，当前不生成视频。

## 已有基础

多上游/多模型/绑定/路由、Windows DPAPI 凭据版本、配置事务与备份、能力及价格分层、并发和配额、只读型号目录观察、稳定编号选型、任务快照恢复、历史对账均已存在。本次复用这些基础，没有另建一套上游数据库。

## 本次实现与验收清单（dev45）

| 项目 | 完成行为 | 验证重点 |
|---|---|---|
| 上游资料长期归档 | 配置含文档索引；副本按上游和哈希保存，支持 API/模型/价格/示例/故障/备注 | 原文件不改，版本追加，重复导入幂等，文件完整性检查 |
| 资料与模型关联 | 文档记录来源、时间、哈希和相关 binding 指纹 | 合同变更时提示，跨账户关联拒绝 |
| 名称与别名 | 星光AI/算力AI等保存别名，稳定 ID 优先 | 同名账户不猜，精确 remote_model 大小写不改 |
| 每上游首选模型 | 图片与视频各自保存首选，不改全局默认 | 显式 model/项目选择优先，首选不适用时不偷偷换模型 |
| 一次读取上下文 | profile-show 返回资料路径、当前参数、价格、并发与已实现协议摘要 | 不解密凭据，不联网，不创建任务 |
| 新上游接入 | profile-import 增量配置与文档，预览 token 绑定原文件/配置 | 过期预览拒绝，共享账户恢复入口不丢 |
| 密钥更新 | 私有 stdin/环境引用；DPAPI 新版本保存 | 预览不读 Key，Key 不进入参数/JSON/输出，旧版保留 |
| 当前配置位置 | config locate/use，跨新对话记住生产配置 | 显式参数/环境优先；选中路径丢失不退到其他账户 |
| 故障与能力分离 | incident 资料保留用户确认及失败证据 | 不自动停用型号、不变更任务或触发重试 |
| 历史拒绝对账 | 保留之前 T/V 精确回执修正 | 非通用 HTTP 400，账单仍未知，不自动再提交 |
| 使用说明与交接 | 技能入口路由、完整操作文档、七条视频本机交接 | 个人素材、任务与凭据不随代码推送 |

## 后续可选增强

这些不是本次命名接续所需的阻塞项：

- Web 页面增加资料上传、版本差异、别名/首选编辑；当前由 Codex/CLI 完整处理，Web 继续共用并保留配置。
- 文档 URL 的显式更新检查及差异提示；当前先读取用户提供的链接、保存原资料，再导入，不后台自动爬取。
- 对新协议增加专门 adapter 与集成测试；不能承诺任意 API 文档自动变成可执行协议。
- 如用户需要跨电脑使用，再做选择性导出与导入；DPAPI 凭据不能直接跨 Windows 账户复制，二进制文档分享需要检查敏感内容。
- 内容质量仍需另行验收：身份替换、原生对白、动作连续性、R05 红印及 R07 小奶牛等不能由配置检查代替。此次不新增视频请求。

具体命令、导入格式、配置位置优先级和边界见 [上游档案操作说明](../videocreate/references/upstream-profiles.md)。实际测试与推送结果记录在本次交付说明中。
