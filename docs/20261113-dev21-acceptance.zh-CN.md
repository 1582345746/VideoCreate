# VideoCreate dev21：已有视频的本地剪辑流程

日期：2026-11-13；版本：3.0.0.dev21。本批推进原路线图 F04/F08/F09、H04/H08 与 J05/J07 的相关范围；73 项总目标保持进行中。

## 功能与边界

过去 v3 校验强制每个项目都有生成 job，本地视频无法独立进入制作阶段。现在 `plan init --profile edit-only` 创建空白剪辑草稿，`production import-clip` 或管理器项目面板导入 MP4/MOV/MKV/WebM，并按实际源片区间追加时间线。原片保留，项目副本记录哈希、实际媒体信息和来源关系；本地 FFmpeg 完整解码通过才登记。无需上游配置，不创建远端 job、预算预留或模型请求。

| 范围 | 本批行为 |
| --- | --- |
| 来源 | `generation-plan.local_sources` 单独存放本地来源；时间线沿用 `clip.job_id` 作为来源查找键，此分支指向 local source ID，不伪造运行任务 |
| 文件 | 原文件不改；内容相同的导入共享一份项目副本，不同来源 ID 保持独立保留区间。实际哈希/时长/宽高/音轨/fps 与登记信息必须匹配 |
| 编辑 | 复用现有时间线渲染、字幕、独立声音轨和叠加；默认保留实际音轨，CLI 可显式 `--mute`。源片区间不得超出实际时长 |
| 阶段 | 空草稿提示导入；未使用大纲、剧本、生成阶段跳过并说明原因。本地来源可用性与审核状态分开列出 |
| 阅读稿 | `production script-export` 对本分支导出来源、原片区间、成片区间、速度和声音的剪辑清单。结构化 script JSON 仍只投射 director，不宣称双向编辑时间线 |
| 审核 | 导入源片与最终成片分别建立实际字节和保留区间合同；动作仍需视频观察，声音仍需听审。字幕变化使成片需重渲染，不创建视频任务 |
| 交付/统计 | 交付清单单列本地来源。统计保留播放秒数和去重源片秒数；导入不计入模型生成次数或生成镜头合格率。未完成实际审片保持 review_pending |
| 管理器 | 类型化区间表单，后台复制/哈希/解码，避免导入期间阻塞 Tk 主线程；空草稿也可打开步骤面板 |
| 保存失败 | 写入前保存三层备份；普通写入错误尝试恢复原始文件字节，失败时给出备份位置。未承诺多文件断电原子性 |

仅剪辑目前支持本地视频。纯图/GIF 的阶段与交付、混合本地/生成项目、完整时间线可视编辑器仍未完成；不将这些范围计为本批成果。
