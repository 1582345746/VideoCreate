# 上游目录和操作记录的迟到响应保护

日期：2026-11-14。对应 W14/W15/W21。当前候选 r16，仍为未发行 dev44；C 盘稳定安装仍为 dev43。

## 修复结果

切换上游时，旧目录请求不再占用新上游的读取状态。目录成功结果、错误和结束读取状态均绑定发起时的页面、上游及配置上下文；A→B→A 也会产生新上下文。离开检查页或刷新配置立即清除旧目录和导入选择。新上游仍只读本机记录，只有明确点击“检查目录”才检查上游；已经发出的请求不会因此被声称取消。

逐操作记录改用配置指纹，而非只看修订号；每次切换接入、配置变化或组件卸载均使旧请求失效，成功和错误采用相同规则。服务返回实际用于读取记录的配置指纹及接入 ID；与当前详情不符时清空记录并提示刷新。即使配置文件在读取记录过程中变化，返回指纹仍描述已经读取的那份配置。读取中、读取失败和确实没有记录分别显示，不把读取中的空白当作没有证据。

本批没有新增或提升合同、小样或质量记录。目录、合同、小样和内容质量继续各自独立。
