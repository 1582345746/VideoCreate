## 用户能看到的变化

“只读检查 / 导入目录”现在打开“上游目录变化与草稿导入”，显式执行一次目录 GET；“查看已保存目录”直接打开本地记录，不联网、不读取密钥。表格展示远端原样 ID、相比上次的新增/未再出现、本地接入以及是否可导入，支持搜索和五种视图。此前出现、从未导入但本次消失的型号也有变化行，不会混入“本地未出现在目录”。长列表和远端 ID 可滚动查看。

首次观察不冒充有上一份基线；完整空目录是有效观察，但不删除或禁用已有接入。刷新失败、响应不完整、重复 JSON 属性、非法 ID、非 UTF-8、超大响应或本次密钥被反射进型号名时，不保存该次观察，也不替换上一份完整记录。

目录记录按上游 ID、地址与非秘密账户标识隔离，同账户凭据轮换可继续比较。观察保存 URL、带时区时间、原样 ID 列表与内容 SHA-256，不保存完整远端响应。损坏、不支持或哈希/文件名不符的历史文件保留但不参与自动比较，报告显示忽略数量；旧无账户范围的 `runtime/catalogs/` 原样保留，不作基线。

本地 SHA-256 仅校验记录完整性，不是远端签名。一次账户目录中的名称可见/消失都不证明协议、能力、可用性、价格、品质或正式下线。

## 来源导入与原数据保护

选中当前观察中的型号后，只新增禁用、`unconfigured` 草稿，带目录 URL、观察时间与哈希来源。已有接入的备注、价格、限制和启用状态保留；大小写原样保留，不自动合并跨上游同名型号。应用仅修改管理器内存，仍需主窗口保存配置。

GUI 导入前核对配置指纹并重读来源观察；配置或文件变化后拒绝旧结果。重复导入已存在的原样 ID 不把管理器标记为已修改。关闭可以保留尚未应用的媒体类型/家族；关闭窗口停止 UI 回调，已开始的 GET 可继续完成并保存记录，不取消后台操作。

CLI 新增 `providers catalog-show --upstream ID [--file OBSERVATION_JSON]`。`providers import-models` 可用完整报告或原始观察 JSON，检查来源范围和所选 ID，预览不写配置；应用沿用现有 `--token` 并发保护。原手工 `{"ids":[...]}` 格式保持，但不自动赋予目录观察来源。
