# VideoCreate dev36：v3 相邻片段转场

日期：2026-11-13；版本：3.0.0.dev36。推进原路线图 H04、F07、H06、C03、J05/J07 的相关范围，完整 73 项工作包仍保持进行中。本轮没有新增真实上游生成请求。

## 实际功能

v3 时间线新增相邻片段的交叉淡化、经黑场过渡和向左擦除。每个转场用稳定的前后片段 ID、类型、重叠秒数及原片声音策略描述；未列出的边界继续硬切。声音可交叉淡化，或在重叠中点硬切到后片段，不改变说话速度；后者会舍弃前片段尾部和后片段开头的相应音频，必须实际听审对白。

管理器“剪辑时间线与声音”新增“片段转场”页，能增改删除转场、刷新片段选项、在比例图上查看紫色重叠区间和点击定位。保存继续复用版本绑定的 authoring 预览/保存事务，只修改 timeline，不创建任务或更改账本。重排、改名、删除片段后，旧边界必须显式修复，不能静默移动到另一镜头。GUI 表单支持已有数据无变化往返；删除转场恢复硬切。

重叠会缩短成片时长。timeline map、表单预览与 FFmpeg 渲染共享相同映射；源片字幕随所属片段进入新位置，绝对字幕、独立音轨和叠加仍保留成片时间，越过缩短后边界会报错。叙事项目仍须满足 brief.target_seconds。转场时间线的片段播放时长和重叠时长都必须对齐输出帧；拒绝不足一帧、超长、非相邻、重复边界、未知参数及三片重叠。渲染使用独立临时文件，技术解码及输出时长/帧数核对通过后替换成片；组装失败保留此前视频、字幕和清单。

原生音轨、静态图停留、变速片段、有理数帧率与硬切/转场混合均走统一渲染。音频先按实际映射归零并裁齐时长；本机 FFmpeg 的 xfade 需要在时间戳归零后重设恒定帧率，真实渲染测试已覆盖。没有自由拼接滤镜字符串、自动下载依赖或上游请求。

统计保留已有“源片贡献播放秒数”含义：重叠时两段素材分别计数；新增 output_timeline_duration 和 transition_overlap 明确真正成片时长及重叠秒数。历史每已审片播放秒成本的分母仍是源片贡献之和，文档明确其含义，不暗中改变指标。原片审核结论不会自动批准转场和成片；通过剪辑成片反证源片的 mapped_view 若触及转场区间会被拒绝，未混合区间仍可按原规则验证。

文字分镜 HTML 标示同时出现的两段计划；文字卡 MP4 使用同一转场组装和真实缩短后时长，仍为 draft_preview，不代表生成画面。动画小样只保留所选相邻片段间的转场，源字幕保留锚点；绝对事件在偏移一致的重叠区间只映射一次。裁切导致同一事件有冲突位置时明确拒绝，需在完整时间线作者层处理。原小样范围和实际媒体审核要求保持。

## 格式与兼容边界

新转场使用 timeline.format_version=2，项目 schema 仍为 v3。GUI 新增转场时设置格式；CLI 需显式填写。无转场的既有映射返回结构和时长保持。发布的计划 JSON Schema 与运行时生成结果同步。

已用实际 dev35 旧 CLI 对独立合成项目核对：旧完整计划校验拒绝新字段且不改项目；**旧直接 timeline map 会忽略转场，返回 2 秒，而新映射为 1.5 秒**。旧直接渲染命令同样没有可依赖的格式保护，因此格式 2 必须使用 dev36 或更新版本处理。未把旧完整计划拒绝解释成所有旧入口均安全。此限制在技能和文档中说明；本轮未迁移或改写真实旧项目。
