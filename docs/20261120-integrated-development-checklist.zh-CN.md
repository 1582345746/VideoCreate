## 约束

- 只在 F:/VideoCreate 开发；保留全部未提交修改、既有视频、原始参考和历史回执。
- 保留 C 盘配置／DPAPI；不全局替换历史路径，不为迁移重新生成已有样片。
- 不自动停止、开启或迁移素材服务；历史服务端口／PID 不是当前运行状态证明。
- 配置 Web 只配置上游；旧 Tk／EXE 保留兼容，不扩展为视频工作台。
- 角色原图定义身份；失败生成不能自动成为新标准。
- 画面动作、可见口型、可听音轨独立；最终无声不等于生成时禁止说话。
- 复刻声音必须实际提取并按需分离人声，向支持该组合的上游发送音频参考。
- 参考视频时间、提取音频时间、生成素材时间、剪辑时间必须映射。
- 30 秒一次完整生成不自动拆为两段；多个参考文件不等于多个输出请求。
- 模型声明、已发送参数、生成成功、内容通过、用户采用、实际收费分别记录。
- 严格动作和口型分别核验；没有实证不承诺逐帧复刻。
- 图片预审、连续剧依赖和顺序／并发按用户具体要求；通用模板不得覆盖已确定偏好。

## 六类流程覆盖

| 流程 | 验收结果 |
|---|---|
| W1 原创视频 | 一条完整原创短片或经明确授权的多段叙事，事件因果与观众理解清楚。 |
| W2 参考改编／换角色 | 角色完整替换，原片必保留事件、动作节奏及声音要求贯穿请求与审片。 |
| W3 图片驱动表演 | 可直接使用原图和可选动作参考；不强制故事结构或额外生图。 |
| W4 有来源的科普／新闻／历史说明 | 主张有来源，旁白与字幕准确，生成示意和事实证据区分。 |
| W5 已有素材剪辑／混合制作 | 本地部分不产生远端任务；缺镜另走生成；所有派生保留源时间和审核范围。 |
| W6 图片／角色设计／GIF | 独立生图和本地动图都能交付；只有需要变视频时进入视频流程。 |

W1–W6 是制作流程；历史 Web W01–W22 是配置子项，编号空间不同。声音版本、系列和精度是组合选项；不要求纯图片项目执行对白或视频审核。
