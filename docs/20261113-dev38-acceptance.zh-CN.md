## 现在可以做什么

管理器首页新增“迁移旧剪辑计划”，CLI 对应 `production legacy-edit-preview` 和 `production legacy-edit-import`。读取旧原生 `edit-plan.json` v1/v2，先预览真实文件哈希、媒体信息、完整新计划、字段映射及差异，再按同一预览 token 导入。新项目为独立的 v3 edit-only 目录；原项目、任务、账本、clean master 和旧成片保持，不继承任何审核。

支持裁切、恒定速度、全局/片段滤镜、cut/dissolve/fade-black/wipe-left/slide-left、循环音乐、旁白、UTF-8 SRT、画面淡入淡出及可选响度目标。中文旧输入 ID 映射为稳定的 ASCII ID，原 ID 和原计划保留。迁移清单位于 `migration/legacy-edit.manifest.json`，原计划与字幕快照位于 `migration/source-files/`。

导入先在目标同级暂存目录复制并逐个完整解码音视频，重新检查源输入和预览 token，验证新计划后才发布新目录。拒绝既有目标、源内目标、包含源的目标、源外路径、缺文件、未知执行字段及非 native backend。失败不发布目标；异常进程中断可能留下暂存目录供检查。这项独立目录导入不等于已实现任意既有项目的多文件断电事务。

## 格式 4 与兼容范围

时间线 format_version=4 增加片段原声 `source_gain_db`、独立音轨 `loop`、最终画面 `fade_seconds`、`mix_limiter` 及 slide-left。管理器“剪辑时间线与声音”、Schema、校验、渲染与清单共用这些字段。旧格式 1/2/3 保持；实际 dev37 wheel 的计划校验、直接 map 和 render 均拒绝格式 4，测试项目哈希保持。

原声增益范围 -60 至 60 dB；循环重复整个音频源，再按填写区间裁切；画面淡化在叠加和字幕之后，不淡化声音。省略字段保留此前行为。迁移按旧流程保存音乐 0.20、旁白 1.0 的线性增益；有旁白时原声 0.35，仅有音乐时原声 0.75，无额外声音时 1.0，写入新计划时换算为 dB。迁移关闭新混音 limiter，循环音乐覆盖全片，旁白在实际长度与成片结束的较早处结束。

旧原生 renderer 实际使用 30 fps，冲突 fps 字段需先显式修正；转场与片段播放时长须符合 v3 帧网格。未核实的 overlays、样式 markup、SRT timing extension、重叠烧录字幕和旧 renderer 未消费的 `preserve_source=false` 均拒绝，不猜测替代设置。当前 Pillow 字幕、二遍 loudnorm、编码及部分混音算法与旧版不同；迁移不保证字节或听感等价，须与旧成片实际比较。

改动后的画面/声音不能通过成片映射反向批准原素材。新项目须渲染并重新播放/听审，交付保持 draft_preview/review_pending；技术测量、保存成功或完整解码均不代表内容已合格。
