# VideoCreate dev27：项目素材卡片与参考对照

日期：2026-11-13；版本：3.0.0.dev27。推进 G02/G03、F06/F07/F08 和 J05/J07；原 73 项工作包总目标继续进行。

## 本轮实现

项目面板新增“角色与项目素材”，剧本编辑也使用同一组表单。角色、场景、道具、声音卡片直接读写 director.assets，与主题、大纲、分镜共用版本绑定的 authoring preview/save；单独编辑卡片时，场景和镜头保持原值。

| 内容 | 实际行为 |
| --- | --- |
| 卡片 | 编辑稳定 ID、类型、说明、来源和固定特征，支持增删及排序 |
| 身份与美术 | 可分别填写身份/面部/物种结构、服装、表情范围、美术风格；构图保留在镜头 |
| 物理条件 | 可分别填写尺度、初始摆放/可达性、接触与承重条件；不宣称文字即可保证模型执行 |
| 本地参考 | 后台复制图片或声音，验证复制哈希，保存到项目自有的完整哈希文件名；原文件不变 |
| 保存语义 | 导入先加入未保存列表，保存卡片才建立引用；移除引用和取消编辑不删除已复制文件 |
| 对照页 | 本地 HTML 显示已保存卡片、参考图/音频、任务首帧参考、当前选中生成原片和相关本地来源 |
| 影响 | 只有镜头引用的卡片设计进入对应任务提示词；保存前显示输入变化，不改原任务或自动重做 |
| 复用 | 新设计字段随不可变素材库版本入库、导入；旧版本和旧项目快照保留 |

新增 CLI：`assets stage-reference PROJECT --source FILE --asset-kind character|scene|prop|voice` 与 `assets board PROJECT --asset-id ID`，均不读取上游配置、不创建生成任务。图片本地上限 48MB、声音 256MB，仅属于导入限制；图片检查格式标识/GIF 结构，声音使用 FFprobe，不代表完整视听通过。

导入后的卡片参考不会自动上传或发送给模型。模型参考仍由明确的 job typed reference 决定；声音样本也不会自动变为克隆声线。对照页只显示已保存版本，任务首帧参考不等于视频实际首帧；缺失或哈希不符的已知快照/候选排除于播放器。导出期间计划、任务或展示媒体发生变化时拒绝混合版本。

## 审核合同变更

源片合同现在绑定其镜头 asset_ids 和台词 voice_asset_id 对应的卡片、参考文件哈希及可用性。改相关身份说明、设计或参考文件，会让该源片旧观察过期；无关源片观察继续有效。任务、候选、账本和审核原记录不删除、不改写。

升级到 dev27 后，旧版缺少卡片上下文的通过记录需要按当前合同复核；这是审核依赖修正，不要求重新生成。最终成片仍需自己的当前审核，打开/播放对照页不授予通过。
