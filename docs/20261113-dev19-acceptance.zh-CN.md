## 解决的问题

原管理器只识别顶层每次/每秒报价：已按条件档位录入的 Seedance2.5-V 在主表会只显示币种，缺少金额。“比较型号”也是当前列表的 JSON 汇总，用户难以并排检查用途、参数、备注和实际证据。混合参考组合、布尔开关和条件价格仍依赖手写高级 JSON。

## 本批行为

| 入口 | 结果与边界 |
| --- | --- |
| 目录主表 | 正确显示条件档位的金额、币种、单位及适用操作/分辨率；可按图片/视频、家族、搜索、收藏筛选，按配置/名称/上游/家族排序 |
| 型号详情 | 可读字段显示上游/账户、精确远端 ID、操作、报价、执行约束、供应商声明、来源、多层备注及文档；草稿显示未配置，不从声明推导默认执行能力 |
| 比较所选 | Ctrl/Shift 选 2–4 个具体 binding，按主表顺序并排查看；支持同一操作/时长/分辨率/画幅下的估算与参数范围预览，不改变选择、默认、任务或全局配置 |
| 估算 | 复用预算核心的条件匹配、最低计费、向上取整与价格有效期；保留各币种，不兑换、不按金额排名；未知/过期/重叠条件/声明价不冒充预算报价；实付始终另行核实 |
| 逐操作实测 | 分别读取每个操作的目录、合同、小样、质量回执；文生视频成功不使图生视频通过；失效证据不计入有效通过，失败不会被成功记录掩盖 |
| 价格表单 | 条件档位可增改操作、分辨率、画幅、秒数范围、每次/每秒费率；保留 0 费率，拒绝非有限/负数/倒置区间；未列入普通表单的字段继续保留 |
| 备注/参考表单 | 上游与型号备注支持多行；七种图片/视频/音频组合可勾选，音频参考与声音生成混用可填是/否/未知；0 与 false 不被误删 |
| 单型号修改 | 编辑、收藏、归档和设置以后默认时拒绝多选，避免把比较选择误用于单条修改 |
| CLI | `providers compare --binding A --binding B --seconds 5 --operation text-to-video --resolution 720p --aspect-ratio 16:9` 与 GUI 共用比较模块 |

比较只检查参数范围。没有实际引用时仍不能通过参考完整预检；素材哈希、直链、凭据、提示词和最终请求由已有生成预检核对。界面显示已启用不等于账户就绪，更不代表成片质量已通过。
