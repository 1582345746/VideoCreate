# VideoCreate dev41：按任务筛选上游与型号

日期：2026-11-13；版本：3.0.0.dev41。推进原路线图 B01、C04、J02/J03 的相关范围，完整 73 项工作包保持。

## 用户能看到的变化

管理器新增“按任务筛选”和“清除任务筛选”。可填写文生视频、图生视频、多媒体参考视频、文生图或图片编辑操作，再填写适用的时长、分辨率、画幅、声音开关，或勾选检查图片/视频/音频参考数量。空白参数不参与筛选；参考数量未勾选时不假设为 0，勾选后 0 表示明确不使用该类素材。

预览显示全部目录的“参数范围相符”“不符合”“未核实”数量，并可查看每个条目的原因。应用到目录后继续叠加上游、家族、媒体、搜索和收藏条件；勾选显示排除项后，主表及详情也解释未匹配原因。清除任务筛选保留其他筛选条件。修改条件会使预览失效；关闭取消会保留尚未应用的输入。

应用仅改变当前管理器目录视图，不写配置、不改变项目/全局默认或编号选择，也不读取凭据、参考文件、URL 或上游服务。配置在预览后变化时，应用按当前配置重新评估，不把旧配置写回来。

CLI 使用 `providers filter --scenario-file TASK_JSON`，默认输出范围相符的条目；`--include-excluded` 显示全部条目和原因。可组合 `--upstream`、`--kind`、`--family`、`--query`、`--favorites` 和 `--order`；场景格式见技能的 `references/provider-management.md`。筛选不创建编号菜单或生成请求，正式选型和预检继续使用原入口。

## 规则共用与边界

时长范围/步长、分辨率条件、画幅、声音控制与完整请求共用标量校验；类型数量、总数、混合组合和参考音频/生成声音冲突与实际多媒体参考共用校验。旧图片协议继续区分总图片数与附加图数量，不能借筛选获得视频/音频参考能力。正式完整请求仍逐项验证参考角色、顺序、MIME、字节、时长和 URL，不使用虚构素材满足筛选条件。

备注和供应商声明不授予能力；禁用、归档、草稿或未登记路线不能成为匹配项。未知多媒体合同或声音能力保持未核实，不按无限支持处理。报价复用原预算规则，按自身币种展示；缺少视频时长、价格未核实或条件不唯一时金额未知，不进行跨币种排名或声称实际付款。

范围相符不证明提示词、实际参考素材、凭据、上游可用性、完整预算或生成质量通过。图片任务不接受视频时长、分辨率、画幅和声音条件；图片尺寸、质量、GIF 等仍由实际图片请求预检核对。本轮不包含新的收费生成或内容审核。

同时修正标量校验遇到 NaN、无限或错误类型时长时的算术异常：现在返回参数错误，不抛出取整或比较异常。
