## 实际功能

仅剪辑和混合视频项目新增“导入静态图片”，与 CLI `production import-image PROJECT --source IMAGE --source-id ID --duration SECONDS [--shot-id ID]` 共用本地来源服务。PNG/JPEG/WebP 必须完整解码且仅有一帧；动画文件保留独立 GIF/视频流程。复制后以原始字节哈希登记，原图保持不变。可映射已有未覆盖镜头，保留其动作、对白和叙事字段；导入不会创建模型任务或账本记录。

图片来源保存真实宽高、格式与单帧信息，不虚构内在时长和 fps。时间线以 source_in=0、source_out=停留秒数、rate=1、source_audio=mute 表示静态停留，可延长、重复或重排；声音使用独立音轨。现有视频片段、字幕映射和 overlays 沿用统一渲染。渲染在临时图片中归正 EXIF 方向、将透明区域合成黑底，保留原图字节；manifest 增加来源类型并将静态帧重复与真实视频采样分开说明。

发布的项目 Schema 同步支持图片来源及其真实元数据，与运行时生成和 CLI 导出保持一致；既有视频来源仍需实际时长和 fps。

审片页可切换原图、源视频和成片，并列查看。原图只展示身份和画面完整性两层；图片审核证据必须指向该原图路径和哈希，无虚构时间戳。原图不能通过动作、剪辑或声音审核；成片仍需独立观看和听审。修改停留或字幕会使旧成片失效，同时保留仍匹配原图的观察记录。

指标单列静态图片数量、停留播放秒数和已审核停留播放秒数。静态停留计入播放时长，不计入实际采集的唯一源秒数、模型生成秒数、请求数或模型质量率。原图审核与模型任务状态各自保存，技术解码与成功渲染不批准内容。
