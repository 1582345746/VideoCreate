## 本批能力

| 层 | 实现 | 边界 |
| --- | --- | --- |
| 项目计划 | 新增 reference-to-video；每项引用明确 image/video/audio、role、path、sha256；attach 有备份与重复保护 | 旧无 kind 的图片计划不自动改写；新旧引用不可混填 |
| 编译与输入身份 | 按类型保留输入顺序，在提示词和 reference_map 标明用途及从 1 开始的序号；源和用途变更影响当前镜头哈希 | 旧未注明 kind 的图片保持原编译输出；链接刷新不修改内容身份 |
| 执行限制 | 每类数量、单文件/总字节、MIME、用途、单文件/总时长；可选宽高/采样率/声道；合计数量/字节和明确组合 | 未知不当作无限；供应商备注不会自动变成执行约束 |
| 上游协议 | 新增 xingapi-video-v2，独立 images/videos/audios HTTPS 字符串数组；保持精确远端 ID、duration/ratio；参数消费报告 | v1 保留文生视频，原任务按已保存版本读取；不自动改变用户 binding |
| 提交与恢复 | 整批在首个预留/POST 前校验全部参数、源文件及公网链接；已接受任务恢复不读取素材链接 | 真正发送后的超时仍进入 submission_unknown，不自动再创建 |
| 凭据与记录 | URL 只在内存中进入请求，项目保留元数据与 DPAPI 引用；v2 创建/查询回显 URL 脱敏，下载走原任务 content 端点 | 文件链接是持有人可读的凭据，撤销不能撤回已取得的文件 |
| 管理器 | 型号编辑新增“多媒体限制”页，复用同一配置校验器 | 常用字段有表单；组合和布尔开关在高级页；人工视觉及干净机器验收仍未完成 |

创建前最后的本地校验如果拒绝请求，记录 proven not-submitted、零费用和未发送证据，不计为已发出的请求；这与已经发送后结果不明的任务严格区分。
