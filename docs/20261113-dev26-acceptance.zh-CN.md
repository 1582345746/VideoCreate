日期：2026-11-13；版本：3.0.0.dev26。继续推进 F03/F06/F07/F08、C05 与 J05/J07；73 项原工作包总目标保持进行中。

## 可操作的制作入口

项目与任务面板新增“编辑剧本与分镜”，直接编辑现有 director 层，与主题、大纲共用 `authoring show/preview/save` 服务和保存前影响预览。没有建立另一份剧本数据库，也没有复制任务或账本。

| 内容 | 当前行为 |
| --- | --- |
| 场景 | 场景 ID、地理布局、摄影轴线、角色与物件位置；支持增删和排序 |
| 镜头 | 稳定镜头/事件/场景 ID、观众信息、用途、构图、开场画面、机位、摄影运动、方向、视线、证据、计划秒数与切镜原因 |
| 动作 | 按顺序编辑 physical/reaction/camera/hold 和具体可见动作，可增删、移动 |
| 表演与节奏 | 显式开启/移除触发、注意、可见情绪反应、选择及动作开始/结果/反应停顿时间约束 |
| 声音与对白 | 显式声音方式、环境音、有序台词、说话者/声线素材 ID、镜头内起止时间、画内/画外 |
| 前后状态 | 保留文字或结构化状态表；复杂嵌套状态不被压成文本；未设置与空状态区分 |
| 引用查询 | 显示当前素材与事件 ID；保留原素材定义、参考与未在常用表单展示的高级镜头字段 |
| 修改和保存 | 只读预览字段差异、整计划错误、实际消费任务与依赖影响；绑定完整计划/编辑值/运行状态，单层备份和原子替换 |
| 阅读与交换 | 剧本阅读稿增加场景布局、轴线、事件对应、计划秒数、构图、机位、对白区间及导演层版本；script.json 保持版本检查 |

例如改一个镜头的台词，仅使消费该对白的生成输入过期；改共享场景布局会显示所有消费该场景的任务。保存不改任务、候选、账本、阶段决定或时间线，不自动重新生成。新建/删除/改名镜头和场景，不会悄悄重映射 job 或剪辑段。镜头表排序不是时间线播放顺序；计划镜头秒数、上游生成秒数和实际保留区间继续分开。

Schema 正确但引用尚未接好的内容可以保存为草稿，原生成、渲染和交付校验仍会阻止执行。删掉被任务引用的镜头或场景时，预览显示缺失引用和受影响任务。空动作数组和错误的对白字段类型属于结构错误，不写回。模型无须在策划阶段选定。

旧 `production script-import` 已接入同一预览/保存服务，媒体哈希工作放在短任务锁之外，提交前复核计划与运行状态；它仍要求完整语义校验通过，不降低成草稿导入。动画 sidecar 拥有的 story/director 从其创作源编辑，表单和交换导入均阻止另起来源。
