## 实际入口与行为

视频项目面板新增“剪辑时间线与声音”，CLI 支持 `authoring show/preview/save --layer timeline`。复用完整计划 source_token、状态绑定的 preview_token、差异预览、单层备份与原子保存；没有另建剪辑数据库。

| 内容 | 本批实现 |
| --- | --- |
| 成片规格 | 独立于生成规格的帧率、画布；共有校验提前报告非偶数及 64–4096 之外的尺寸 |
| 素材映射 | 稳定 clip ID，选择生成任务或已登记本地来源；按钮显式填入登记路径或清除生成素材覆盖路径 |
| 播放片段 | 有序片段、shot/clip 关联、原片保留区间、速度、原声策略和剪辑理由 |
| 独立音轨 | 台词/环境/音乐/音效，素材或项目文件、源区间、成片进入时间和增益，保持自然语速 |
| 字幕 | 按稳定片段的源区间定位，或成片绝对时间定位；显式切换坐标方式，移除旧坐标，不猜测换算 |
| 叠加 | 原有渲染核心消费的文字/项目图片、时间区间和位置；字幕仍单独导出 SRT |
| 比例示意 | 显示当前未保存的画面、音轨、字幕和叠加；点击画面定位片段表单；不是视频播放或内容验收 |
| ID 选项 | 显式刷新未保存的素材/片段下拉选项，保持当前字段，不自动补关联 |

源片字幕随对应片段的顺序、裁切和速度映射；成片绝对字幕、独立音轨与叠加保留原来填写的成片时间。裁掉字幕、截断台词、无效速度、慢放原声、缺失 ID 等继续由现有完整计划和时间线校验报告。结构正确但不完整的内容可保存草稿，保存不表示可以渲染。

保存只改 timeline，活动/未知生成任务也不因此被更改；task ID、路线快照、候选、账本、原媒体和其他创作层保留。原生成任务的输入未因字幕改动而改变。动画允许编辑本地时间线，原动画 sidecar、剧本和任务保持原来源；明确重建动画计划仍可能覆盖投射出的时间线。纯图/原生 GIF/本地 GIF 集合没有视频剪辑层，继续使用原任务和转换配方。

文件按钮仅关联项目内已有文件，不复制、不上传、不进行内容判断。实际媒体检查与音轨/叠加哈希继续由渲染核心完成。`clip_id` 非空时声音使用该素材，否则读取 path。表单不调用生成、渲染或审核；保存后通过现有 `timeline render` 生成新的剪辑，再实际播放审核。
