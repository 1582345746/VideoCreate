## 实际功能

项目面板新增“生成任务执行”，与 CLI 的 `jobs prepare/execute` 共用 `generation_actions` 服务。支持明确选择视频、纯图片或原生 GIF 的生成任务，预检所选任务及其视频依赖，显示原接入、新尝试固定接入、每次报价、未知价格和预计新增请求数。重做内容或按新计划重做必须选定一个任务并填写原因，保留原任务、候选和账本。

缺少上游/模型选择时，面板显示已有的稳定编号菜单，可选择仅本次或当前项目；仅本次选择不会保存为全局默认。选择后重新预检，执行时固定到预检展示的接入，不隐式切换备用站。

预检不创建媒体、不预留预算；参考素材可能需要读取 HTTPS 文件核对哈希。预检 token 绑定完整计划、任务/账本、已保存配置、项目选择、操作参数和请求指纹。执行再次预检，变化后拒绝旧方案。本次新增请求上限只能降低原项目上限，所有新增请求先在原账本副本上模拟预算。

“仅恢复原任务”以及 `jobs resume PROJECT --job ID` 禁止创建请求：整批依赖检查和运行时状态锁内都核对原任务号，沿用原 URL、账户与版本化 adapter。修改默认或停用当前接入不会把原任务转到新站。未知提交仍需实际对账证据；图片同步接口仅复用当前已完成结果或重处理已保存原响应，不虚构异步查询。

面板在后台执行并显示进度。重复点击只启动一次；关闭窗口撤销界面回调，已经开始的操作仍按原等待/网络上限结束，不代表远端取消。另可导入原有未知提交对账回执、实际账单回执，使用已有验证服务。

同时修正旧运行时按新计划重做的范围：只有明确选中的任务可放行变化输入，依赖任务发生变化仍需单独处理。
