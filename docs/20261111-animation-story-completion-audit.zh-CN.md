# 动画故事模块逐项核验

日期：2026-11-11；软件版本：3.0.0.dev12。依据原开发计划 A01–A20、M1–M4 和用户后续指令。用户已选择 Grok 及视频生成原声，并允许直接原创剧本；不把外部配音服务作为这条路线的前置条件。以下按要求判断证据范围，不把软件通过等同于生成质量通过。

## 开发清单

| 项目 | 当前实现及可检查证据 | 尚未证明的部分 |
| --- | --- | --- |
| A01 契约与兼容 | `animation/schema.py`、`project.py`；动画上下文版本 1 投射 v3 五层计划；公开 Schema 同步测试、旧入口回归 | 无新增迁移型字段；旧项目仍按原版本读取，不做隐式升级 |
| A02 参考管理 | `animation inspect`；来源哈希、媒体规格、用途、重复检测；实际 12 片及 Unicode 路径回归 | 原视频只保存在本机，公开包不附带用户素材 |
| A03 理解接口 | `study.observations/segments`；静帧、OCR、ASR、听音、连续视频分别声明；区间抽帧及证据哈希校验 | 当前工具只能检查静帧，不能据此声称完整听审或动作理解；人工输入入口可用 |
| A04 骨架与要点 | `outline`、`core_points`；source/original/user 区分、原始秒数及证据关联；真人家务来源有五条观察 | 原片情绪解释仍含明确推断 |
| A05 改编 | `adaptation.point_map`、casting 与原创设计；漏要点、断因果回归；真人剧情有两套主题计划 | 结构覆盖不证明观众实际理解所有情绪反差 |
| A06 角色主题 | 版本化 `lulu-lumei`、`cloud-couriers`，自定义主题、服装变体；注册用户图和裁剪来源，独立集共享参考；用户已接受 `film-lulu-action@2.0.0` 最新打斗输出的脸部 | 内置文字包并不自带完整表情图库；本次接受不自动认证未来生成或替换日常主题 |
| A07 场景 | `scene_designs` 的 description/layout/scale/lighting 与投射布局同步；柑橘小屋和云上驿站各有独立设计 | 模型能否实现尺度及接触仍需看样片 |
| A08 表演分镜 | 因果、表演、可见接触、动作阶段、每镜 timing；动作负荷和阶段预算测试 | 提示词期限并非实际动作速度保证 |
| A09 关键帧 | `animation reference/keyframes/select`；身份指导和首帧分开、逐项哈希观测；真实鸭嘴及道具候选保留 | 单帧通过不认证连续视频身份；电影脸旧候选已被用户否决 |
| A10 生成编排 | `animation run` 共用 runtime；相邻小样、扩展门槛、依赖、模型/绑定快照；dev12 整批本地检查四项回归 | 原 Muse 未知请求未解决；当前按用户选择使用 Grok，不重发该请求 |
| A11 声音字幕 | 原生对白规划与原声保留、独立音轨显式入口；未听审脚本不自动成为字幕；已实际核对男女声和口型 | Grok 曾改词和额外接话；逐字可控、跨集固定音色未证明 |
| A12 剪辑审核 | `animation preview`、timeline、七层审核及逐题眼审核；真实 MP4、SRT、manifest、时间映射；闪跳版有失败记录 | 部分完整题眼仍无播放证据；不得将小样当作全片认证 |
| A13 独立系列 | `animation series-init/episode`；主题与声线快照、独立初态、共享参考；保留 serial | 软件隔离已测，未宣称已量产一个完整系列 |
| A14 固定配音 | 显式可选的 voice-cast、已有 loopback 服务桥接、局部失效与缓存回归 | 本轮未验证独立配音音质或非人脸独立轨口型；用户选择原声，此路线不强制启用 |
| A15 互动库 | `library-add/library-list`；真实取饼干递接、递靠垫靠肩区间，绑定首帧、前置条件与播放回执；来源失败撤销可用性 | 两条已审核互动不等于完整通用动作或表情库 |
| A16 局部修复 | 输入哈希包含本镜、参考字节与画幅；字幕/独立声音不创建新视频；旧候选、重做原因保留 | 换脸后依赖该身份的素材仍须重新生成和审核 |
| A17 记录成本 | 持久账本、已知/未知价格、失败/重做、完成秒数与审核可用秒数；预算并发回归 | 没有供应商已核实账单，不将已知金额小计 0 解读为免费 |
| A18 第二主题 | 同一真人剧情来源、观察和四个要点 ID 的狐狸/兔子离线改编通过；另有真实 14 秒第二主题小样及用户反馈 | 新的真人剧情狐狸版尚未生成，旧第二主题视频未获完整精细题眼认证 |
| A19 更多题材 | 已按用户后续需求试验原创营地和古装火场；最新约 5 秒、1.2 倍连续打斗获用户确认“速度合适，脸也可以” | 接受范围是该版本的脸和速度；不能承诺更多美术或多人复杂动作均同等稳定 |
| A20 动作控制 | 保留能力与适配器扩展口 | 未验证的整段视频参考、精确动作控制没有接入为正式能力；原计划列为 P2 后续 |

源代码路径以仓库 `videocreate/src/videocreate/` 为前缀。相关测试位于 `tests/test_animation*.py`、`test_reference_analysis.py`、`test_v3_pipeline.py`、`test_v3_production.py`、`test_content_reviews.py`。dev12 本地完整 472 项通过；每次交付的 GitHub、安装与包哈希在本机交付回执另记。

## 当前未完成项
