## 可操作入口

非动画、非仅剪辑项目的制作面板新增“生成任务与参考”，直接编辑 generation-plan。与已有主题、大纲、剧本、卡片表单共用 `authoring show/preview/save`、完整计划版本、任务状态绑定、差异预览、备份及单层原子保存；CLI 新增 `--layer generation-plan`，不读取上游配置也可编辑。

| 内容 | 当前实际行为 |
| --- | --- |
| 视频任务 | 稳定任务 ID、有序镜头 ID、操作、上游生成秒数、任务/本地来源依赖、需要已有观察证据的质量项 |
| 图片与原生 GIF | 按项目分支显示提示词、生成/编辑操作、尺寸、质量和格式；保留现有 GIF 输入/输出路径 |
| 接入选择 | 从本机已保存配置列内部型号与具体 binding，可显式按 binding 填入匹配型号，显示上游、远端 ID、启用状态、协议和备注 |
| 有序参考 | 编辑路径、完整哈希、媒体类型、首帧/身份/场景/动作/声音等角色；高级派生记录保留 |
| 文件关联 | 选择项目内文件，在后台检查实际字节并填入未保存行；项目外文件先走素材快照或媒体登记 |
| JSON 导入 | 验证已登记参考 JSON 的本地来源哈希，只保留合同字段；图片任务只接受图片，原生 GIF 字节不抽成静帧 |
| 版本与影响 | 完整计划错误、局部输入变化、现有任务及原路线、未来路线修改范围；不自动修改时间线 |

视频画幅/分辨率继续来自 brief，声音意图来自关联镜头，本轮没有增加未被 adapter 消费的每任务参数。界面显示草稿/禁用接入供规划，保存不启用它，也不证明协议、凭据、价格或能力就绪；实际执行仍走现有预检。留空路线继续沿用项目选择/编号选择策略，不把本次选择改成以后默认。

## 任务与来源保留

此创作服务拒绝改写 submitting、submission_unknown、queued、in_progress、read_pending 等活动/未核对任务。已保存任务的计划条目不能删除、改名或搬到另一媒体类型；新任务也不能占用孤立的历史 ID。无任务记录的草稿条目可以增删、排序。

完成/失败/拒绝的任务可继续规划明确的新尝试，保存不改 task ID、原账户/模型/adapter 快照、候选或账本。路线变更显示原 binding 与“未来明确尝试”的范围；视频已有任务的输入指纹仍排除路线选择以保证原快照恢复，图片路线变更还可能使该图片计划过期。创建替代结果仍需现有指定任务 replan/retry 和有效授权。

本地来源及 GIF 派生记录由原导入/转换服务管理，generation-plan 创作拒绝改动它们。动画 generation-plan 保持 sidecar 归属。新任务不会自动建立时间线片段，任务排序也不是播放顺序。结构正确但镜头引用不全、依赖成环的内容可保存草稿，生成继续受完整计划校验阻止。

以上保护是 authoring 服务的行为；旧的专门素材关联/导入命令继续各自实现，不宣称所有入口已归并为统一事务。已有完整工作包状态仍按原要求核对。
