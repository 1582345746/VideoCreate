# 本机上游配置 Web（dev44 候选）

Web 维护上游配置，制作仍由 Codex、技能和 CLI 完成。普通用户添加上游只需 URL 和 Key；名称、备注可选。远端型号、协议、参数、报价与来源按明确合同整理，不按模型名称猜测。

## 启动

```powershell
python scripts/videocreate.py config-web
python scripts/videocreate.py config-web --config "完整配置路径" --port 8787 --no-browser
python scripts/videocreate.py config-web --read-only
```

Windows 也可双击 `scripts/Start-ConfigWeb.cmd`，或运行 `scripts/config-web.ps1 -Python "Python完整路径"`。Web 是可选依赖；在选定的 Python 环境安装 wheel 的 `[web]` 组，或安装 `assets/web-py39.lock.txt` 中已在 Windows Python 3.9 验证的闭包。运行页面无需 Node。缺少依赖只报告原因，不自动下载或初始化第二份配置。

独立 `videocreate-config-web` 与 `videocreate config-web` 对可预期的启动失败返回结构化错误和退出码 1；PowerShell/CMD 传回同一退出码，CMD 保留出错后的停留提示。`Web dependencies are missing` 表示缺少 FastAPI/Uvicorn；`Web runtime dependencies are incomplete` 表示依赖闭包不完整；`Web runtime could not load` 则需检查所选 Python、锁定包及其运行库/DLL 路径。不要为排除 Node 而清除 Python 环境必需的 PATH。启动错误不回显底层导入异常内容，也不自动修改配置或安装依赖。

默认仅监听 `127.0.0.1:8787`，8765 被明确排除。先绑定并启动，再打开浏览器。端口已被占用时，只复用相同产品、版本、规范化配置路径、模式及实例标识；不打开陌生服务。关闭浏览器不会停止配置进程，按终端 Ctrl+C 结束配置服务。它与素材服务、Codex 和已启动任务的生命周期独立。

设置页显示实际解析配置路径、运行版本、Schema 和修订。仍用原 C 盘配置与当前 Windows 账户的 DPAPI 凭据；没有显式初始化请求时，缺失配置保持缺失。Schema 3 需先通过 CLI 预览迁移，未来 Schema 保持只读。

## 保存与恢复

- 表单只有一个保存动作，后端执行不可变预览与提交。冲突返回 409，需要重新读取并合并。预览十分钟有效，绑定来源配置及当前会话。
- 从请求预览到提交、刷新和草稿清理结束，上游/模型字段、默认选择及恢复中的备份选择暂不可编辑，页面切换也暂不可用；完成后恢复操作。预览尚未返回时也只允许一项配置保存，连续点击不会再启动另一份预览。保存失败保留非秘密输入并解除本次忙碌状态，Key 仍需按提示重新填写；提交结果不明时先核对原保存。
- Key 只提交到专用凭据保存事务；DPAPI 形成新版本后才提交配置引用。旧版本保留。更换账户或地址请另建上游实例，复制资料不会复制 Key。
- 响应丢失后，上游与模型弹窗内均可“核对保存结果”。核对会等待仍在进行的原提交，不自动再新增；确认已提交后继续原保存的表单关闭、默认基线/备份选择重置和草稿清理。结果未知或核对失败时保持输入锁定，可继续核对或重新打开页面查看配置；确认未提交才解锁，保留非秘密输入，Key 需重新填写。连续点击只读取一次状态。
- 浏览器仅保存原提交的不透明标识。页面重开后核对会刷新当前配置，原非秘密草稿保留并提示先核对再恢复或丢弃；不会将重开后读到的较新草稿版本当作旧提交的版本删除。同页成功清理仍检查原草稿版本，其他窗口的较新输入保留。进程重启后未提交预览失效，已加密而未引用的版本保留；重新检查非秘密输入并按需再次录入 Key。
- 备份使用受控内容哈希编号，浏览器不能选任意路径、读取旧配置原文或下载密文。恢复保留之后新增的身份为归档/禁用条目，旧任务仍使用原快照。
- 损坏 JSON 只能从受控有效备份修复。先保留 BOM、换行和原始字节，再替换。无法解析的原文不能证明包含全部历史身份，确认前应核对所选备份覆盖范围。未来 Schema 即使尾部损坏也不修复。
- 上游的 URL/名称/备注、模型资料、图片/视频默认选择及备份选择约 600ms 后暂存到本机服务，绑定配置和表单版本，七天过期。浏览器只保存不透明草稿标识。刷新或服务重启后必须显式恢复；标签页标识丢失后，可展开“本机未提交草稿”，主动读取列表并选择恢复输入。列表只显示类型、时间与状态，不含名称、备注、地址或表单内容，按配置文件隔离。恢复输入不提交配置，也不执行备份恢复。模型和默认使用配置指纹，损坏文件修复使用原字节哈希；来源变化拦截保存，必须重新读取并明确核对。
- 草稿保存、恢复接管和丢弃都检查精确文件版本；两个共享 Cookie 的窗口也不能覆盖或删除较新的草稿。冲突保留当前输入，暂停该草稿的自动暂存，可明确另存新草稿；已丢弃的草稿不能被旧窗口自动复活。过期、不支持或损坏记录保留供列表核对后按版本明确丢弃。配置保存成功后的草稿清理属于附带操作，清理冲突不改变配置已保存的结果。只读服务可列出和查看草稿，不能接管或改写。
- Key、同账户确认、原始配置和任意路径均不进入草稿。模型高级 JSON 只暂存 Schema 中的已知字段，语法不完整、含未知字段或凭据式来源 URL 的组不暂存并明确提示；其余资料可恢复。未完整恢复时高级提交默认关闭，须重新核对。无效排序文本和备注空白仍保留。防抖保存前强退、磁盘写入失败或未完成的请求仍可能丢失最近输入；已确认暂存的四类输入通过真实浏览器强退和标签页标识清除后的恢复验收。

页面会话一小时有效，HttpOnly/SameSite Cookie 与 CSRF 值分开。API 需要同源自定义头；写入要求 Origin 和 CSRF。Host/loopback 校验、无 CORS、CSP、256 KiB 请求上限和十五秒读入超时独立生效。API 与诊断不回显 raw config、auth、secret_ref、密钥、密文、异常输入或原始错误。

页面首次连接时绑定规范配置路径的不透明身份；后续页面请求携带该身份。同一端口后来打开另一份配置，即使两份内容完全相同，也会拒绝原页面的读取、保存和结果核对；原输入保留，请重新打开页面并核对设置中的实际路径。草稿和待核对提交标识在浏览器中按配置身份分别保留，同一配置重启仍可找回，打开另一份配置不会删除或覆盖它们。标识不含配置路径、表单或 Key。

旧候选的草稿标识只有在当前配置实际加载成功后才移到独立命名空间；另一份配置找不到时保留原标识。旧版待核对标识没有配置身份，点击核对前须明确确认显示路径就是原配置，取消确认不会读取状态或删除标识。不会仅因另一份配置返回“未找到提交”就替原记录下结论。既有明确选择配置的 API 客户端可继续使用原请求格式；页面的身份绑定是额外的上下文保护，不替代会话、CSRF、来源指纹和用户核对。

## 目录、合同和默认

查看目录记录只读本机缓存；点击“检查目录（只读）”才 GET 所选已存上游的目录。没有通用 URL 代理，不发生成 POST，不跟随目录重定向。缓存按地址/账户绑定；鉴权失败、404、不支持格式、超时等不会回滚上游保存。目录变化不删除旧型号。

目录检查失败仍保留与当前精确地址匹配的已有文档，可直接“按此文档整理接入”，不要求先取得目录记录；失败不会产生虚假的目录观察。检查期间若地址、账户或配置有效性改变，返回冲突并要求重新读取；已归档上游不再提供整理按钮。其他地址不会借用此合同。

所选精确 ID 导入为禁用、未配置草稿，不覆盖已有备注/协议；观察超过一天或来源变化需要重新检查。媒体类型需明确选择。缺少 `/models` 不妨碍 Codex 使用已经提供的文档。

模型详情的“接入整理待办”列出草稿尚未记录的协议、操作，以及视频时长/分辨率/画幅或图片尺寸/输出格式。声明和适配器默认值不会填补这些待办。已选择 typed 参考操作而缺少必需素材限制及组合时，也会说明原因；参数已填完但仍是草稿时提示 Codex 核对来源后再启用。此区只读，添加上游仍只需 URL/Key，不改变已有路由、启用、默认资格或请求预检，也不把空待办视为在线验证。

内置文档整理仅提供 `https://xingapi.top/v1` 下 `seedance2.5-V` 的明确文生视频配方，精确保留大小写。候选范围限于 720p、9:16、整数 5–30 秒、模型默认声音；没有自动启用参考素材或推定其他型号等价。已有配置协议不被配方覆盖。其余 XingAPI 文档和已实现适配器继续由 Codex/CLI 按精确操作维护。

模型资料与可选高级参数、声明、展示报价、预算价格、条件档位和来源一次保存，核心统一校验。高级区提供常用能力/执行约束、报价币种/单位/来源/符号、预算价格有效期/最低秒数/取整及档位的结构化输入，与下方 JSON 共用当前模型表单；子表单不单独写盘。无效 JSON 阻止对应结构化编辑，不自动修正文档。清空可选价格组并保存会删除该组，恢复未知，不把空值转换为零；显式填写零价则仍需有明确依据。

图片、视频、音频参考可分别维护数量、单个与总字节、MIME 和角色；另有时长、尺寸、采样率/声道、跨类型总数/总字节、URL 有效秒数、声音输入/输出许可及七类素材组合。未填的合同保持未知，不预设角色或数量；明确不支持的类型需填零和空列表。删除约束组恢复未知；已启用的参考操作若失去必需合同，核心拒绝保存。条件时长可按操作、分辨率、画幅新增/删除上限。其他精确字段保留 JSON，不自动切换 adapter，也不把声明当成实测。

硬预算支持每请求与每秒价格；图片接入另支持 `per_image`（每请求出图张数），可与每请求费相加。图片适配器只有明确发送 `n=1` 时才提供一张的预算依据；省略 `n` 的合同保持张数未知，不推定供应商默认值。参考图数量、GIF 帧数和返回图片数量不作为计价张数。按张价格不能用于视频，也不能与秒费、最低/取整秒数或时长档位条件混用。选中档位会替代基础费率。其他单位只作为展示报价和备注；展示价、预算估计和实际账单分别保留。旧 dev43 校验不支持的 `per_image` 时必须拒绝；回滚前应从新版本明确调整配置，不能让旧版静默删字段。

上游、模型、默认和备份选择绑定打开时的来源；其他窗口先保存后，旧表单返回冲突，需重新核对。对话框打开定位输入，保存刷新后回到原操作按钮。展示价不用于硬预算，未知价格不是零；价格到期、证据未核实、币种不符、档位重叠或缺少匹配参数时，预算估算继续报告未知。图片、视频默认与 ask/use-default 分别设置，仅允许有效启用且已登记到路由的接入。更改默认不修改原项目或 task。

任务筛选、二至四项比较、逐操作证据均离线。比较不展示账户标识或任务/证据路径，不建立无样本质量排名。目录、合同、小样、内容质量记录独立。匿名诊断先预览，来源/证据变化需重预览；导出新文件，不覆盖已有文件。

目录与文档读取只更新当前上游和页面；切换上游、离开页面或刷新配置后，旧响应、错误和读取状态不会覆盖新选择。逐操作记录也绑定当前接入及配置指纹；同一修订号下文件已变化时要求刷新，不把另一份配置的记录套用到当前详情。读取中、读取失败与确实没有记录分别显示；这些读取不会自动检查上游或修改证据。

筛选与比较显示本次计费说明：未配置/未核实、币种不符、尚未生效/已过期、时间无时区、缺少档位参数、无匹配档位、多档同时匹配各有原因。能估算时显示匹配档位及按最低秒数和步长向上取整后的公式；金额与说明共用预算计算，不选择较低档位或自动换算。无效时长与溢出金额保持未知。图片比较无需填写视频秒数。修改任务参数、参考数量、所选接入或配置版本后旧结果失效，迟到的旧响应也不会恢复结果；请按当前条件重新检查。

“所有参数”价格档不作为其他档位的默认后备。已有一档匹配，但另一档仍因缺少分辨率、画幅或操作而不能排除时，金额继续未知，并显示需要补齐的参数；只有排除其他可能档位后才能采用唯一匹配。两个已确定匹配的档位仍报告重叠。未知金额不能证明硬预算上限，执行器会按原预算规则拦截新请求。

## 候选发行边界

安装、升级、配置兼容回滚和卸载见 [候选安装维护说明](config-web-installation.md)。wheel 与 ZIP 均使用独立 F 盘程序副本，保留原 C 盘配置、凭据、项目和稳定安装；当前 ZIP 不包含仓库根目录的历史安装器。

源码仍为 dev44 候选，已安装 dev43 不被替换。真实 Chrome 已验证 100/125/150/175/200% 浏览器缩放、五个入口、键盘打开/Escape/焦点回收及长中文；高倍缩放下表单只滚动正文，标题和操作栏保留在屏内，按钮完整可见并可点击。损坏配置重开页面会读取本机备份状态，可直接恢复修复草稿。浏览器自动化、隔离配置/假上游、仓库外安装与回归是开发证据；真人读屏、全新 Windows 机器、真实新上游生成/账单和内容验收各自保留独立结论。现有 8765 服务及旧 EXE 保留，生产切换未验收。不得为配置测试付费生成或重新生成已有样片。

辅助文字与状态标签采用可读对比度，复选框至少 24px，键盘焦点有明确轮廓。上游和模型编辑弹窗按当前可见、可用控件循环 Tab/Shift+Tab；关闭详情区的隐藏子控件不参与循环，展开高级字段后重新计算。提交待核对或核对失败后，焦点移到当前弹窗的核对按钮；输入锁定时仍可通过键盘核对。Escape 仍走未保存确认，保存等待中保持弹窗；成功后返回原按钮。开发用 axe-core 只作为锁定的前端测试依赖，不进入运行页面或技能包，不要求用户联网加载。自动扫描按 WCAG 2 A/AA、2.1 A/AA 与 2.2 AA 标签检查五入口和编辑弹窗，保留无法判断的项目供人工复核；自动无违规不等于完整 WCAG 认证或真人读屏通过。

主导航标记当前页面，文字旁的装饰图标不重复提供读屏内容；模型收藏星号以“已收藏”名称提供状态。开发核验对可见导航/收藏符号另读实际前景和背景颜色，覆盖普通、悬停与选中状态；仅在不透明颜色、无滤镜/混合/背景图片时判定对比度，其他情况保持待复核。该补充检查不替代真人读屏或完整 WCAG 审计。

候选构建先在 F 盘独立目录重新执行前端类型检查和构建，逐文件比较结果与待打包静态文件，不覆盖运行页面。静态文件过期、缺失或多余时拒绝成功回执。构建记录包含技能源码、前端源码、锁文件、打包元数据和构建检查工具的哈希；复制前后及打包后重新核对，输入增加、删除或变化均需另开候选目录重新构建。Node/npm 只参与开发构建，用户运行仍不需要它们。
