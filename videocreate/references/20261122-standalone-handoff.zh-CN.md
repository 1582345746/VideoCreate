## 2. 角色与声音怎么用

**每人六张。** 两张原始多视图分别是噜噜的橙色短裤造型、噜妹的粉色连身睡衣造型。最新重发的两个 WebP 与入库文件逐字节相同。身份图定义脸型、眼距、宽橙色口鼻、金黄色、短圆四肢及原版头部结构。服装图定义本镜的身体穿搭和头饰。原图上的橘子、叶片和帽沿可以在新帽子上以小装饰呼应。拍原版才要求完整恢复原头饰。

|---|---|---|
| 原版 | 单叶橘子、橙短裤 | 白色荷叶帽、奶油环和双叶橘子、粉睡衣 |
| 春 | 绿色短夹克、报童帽 | 小花裙、针织开衫、花头巾 |
| 夏 | 西瓜短裤、编织宽檐帽 | 草莓裙、粉带草帽 |
| 秋 | 栗色灯芯绒外套、深色鸭舌帽 | 背带裙、莓色贝雷帽 |
| 冬 | 奶油绒大衣、红围巾、翻毛护耳飞行帽 | 粉棉衣、奶油围巾、圆毛绒耳罩 |
| 春节 | 红色盘扣唐装、瓜皮帽 | 绣花红袄、粉裙、虎头帽 |

技能包中的 `lulu/`、`lumei/` 可直接取图和音频。`asset-library/items/<卡片ID>/<版本哈希>/` 保存项目导入用的不可变快照。卡片有 12 张视觉卡和 2 张声音卡，图片数量以独立内容计。拼图仅用于浏览；上游引用选中的单文件。全部相对路径和校验值见本机包的索引。

| 声线 | 来源与处理 | 用途 |
|---|---|---|
| 噜噜 `lulu-voice` | 7.660 秒 PCM。取原片 0–1.400、2.866667–4.566667、6.566667–8.366667、10.066667–12.466667 秒 | `lulu/voice.mp3` 为模型参考，`lulu/voice.wav` 为听审母版 |

人声取自 `e05d3916-da4e-46e8-b07b-276ff81694b7.mp4`，使用 `Kim_Vocal_2.onnx` 分离伴奏，再按说话人拼接。用户听过，确认角色分对、人声清楚、音乐已不明显。包内索引记录原片哈希、分离报告和源时间段。本次逐文件解码并核对来源。新生成台词需要在对应镜头重新听，重点查成年男声偏差、两人串声、句中卡顿和背景音乐。

把已经存在的 v3 项目目录赋给 `$project` 后，按当前版本选卡。例如一条“冬天噜噜在画外说话、噜妹在画内跳舞”的片子可以这样开始。

```powershell
$catalog = python $cli library list --store-root $pack | ConvertFrom-Json
foreach ($id in @('lumei-winter','lulu-voice')) {
    $item = $catalog.items | Where-Object library_id -eq $id
    python $cli library import $project --store-root $pack --library-id $id --version $item.version --asset-id $id
}
python $cli assets board $project --asset-id lumei-winter
```

将造型卡加入对应镜头的 `asset_ids`，将画外台词的 `voice_asset_id` 指向 `lulu-voice`。需要复刻动作时添加原视频和目标时间区间，将项目内的造型图片、动作视频、声音 MP3 显式映射到支持组合的生成任务。检查请求预览中的实际参考类型、数量、哈希与说话人。静音配音版可以保留嘴部表演，输出静音由交付参数与音轨检查控制。双人同框另看身高、肩宽和站位；各自的单人海报采用独立构图，像素高度不能推算两人的身高比。操作细节见[素材库使用说明](asset-library.md)。

私人素材随整包备份。公共 wheel、候选包、公共发布 ZIP 和 Git 源码均排除 `local-cast/`。新对话在本机可直接用 F 盘入口；新电脑需要从个人备份恢复包目录。

## 4. 用真实片子安排开发顺序

| 历史现象 | 先定位的数据 | 开发验收用例 |
|---|---|---|
| 手势舞漏头顶橘子，换人只换了脸 | 原角色图、服装、是否允许更换头饰、原片承担的动作或场景职责 | 露头镜头检查橘子或明确选定的帽子，侧面检查身体和服装也已替换 |
| 五人群舞角色雷同、动作松散 | 两位主角、三位配角的各自参考，前后排站位，起拍、转身、停顿的源时间 | 映射五人可分辨的外观，逐事件对照。遮挡后角色回到原位置关系 |
| 手机跟拍太稳、手机拿反，夸奖台词串声 | 镜头视点、持机方向、持机者身体节奏、边框内外以及画外说话人 | 三个指定时段分别看到拍偏、回稳、边框内外位移；对白按角色逐句听。允许部分身体出框 |
| 洗澡片看见衣服被拿仍继续洗，荷叶挡脸或突然出现 | 视线、道具所在位置、谁何时发现、人物反应 | 逐点标注拿走、发现和反应，遮挡物的位置与前后镜头连续 |
| 雪地滑倒路径不对、摩托出隧道跳切 | 动作起点、方向、再入画位置、持续帧、道路连续标记 | 左下重新入画后向右；隧道口同一运动方向、光线过渡；翘头用侧视连续帧复核前后轮 |
| 营救片只需换城墙将军，模型改了全场 | 指定镜头、区域、原骑手及士兵的保留要求，共享身份外的角色作用域 | 城墙上保留噜妹，城门外骑手保持原版。比较非目标区的大动作、特效与出场顺序 |

优先采用已有媒体做回归。用户采用过的手机片、水牛双人舞可做正例；采用范围限于该候选。新候选分别验角色、动作、镜头、听感与剪辑。严格动作或口型要求需要试验可控的跟踪、局部合成或音驱手段；送出参考片后仍需实测误差。
